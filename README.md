# Путь к дому

Учебный проект: сервис с информацией о приютах и помощи животным.

## Идея

На карте отображаются все доступные приюты в вашем регионе и за его пределами,
вместе с информацией о том, как туда добраться, что требуется для животных,
и как можно помочь.

## Планируемый стек

## Запуск

1. Склонировать репозиторий:

   ```bash
   git clone https://github.com/23hoose/project.web.git
   ```

2. Перейти в папку проекта:

   ```bash
   cd project.web
   ```

3. Открыть `index.html` в браузере (двойным щелчком или через `File → Open`).
