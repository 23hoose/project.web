# Semantic Map — «Путь к дому» (главная страница)

| Визуальный блок / содержание | Назначение | HTML-тег |
|------------------------------|-----------|----------|
| Верхняя панель: логотип, меню | вводная часть страницы | `<header>` |
| Меню навигации внутри шапки | переходы по разделам | `<nav>` |
| Основной контент страницы | уникальное содержимое | `<main>` |
| Герой-блок: заголовок, подзаголовок, две ссылки-перехода | вовлекающая секция | `<section>` |
| Блок «Как можно помочь» с 4 карточками | тематическая подборка | `<section>` |
| Карточка способа помощи (Корм, Лекарства и т.д.) | самостоятельная сущность с заголовком | `<article>` |
| Блок «Приюты рядом» с карточками приютов | тематическая подборка | `<section>` |
| Карточка приюта | самостоятельная сущность | `<article>` |
| Блок с формой заявки | целевое действие | `<section>` + `<form>` |
| Подвал: контакты, копирайт | завершающая часть | `<footer>` |

## Пояснения по спорным случаям

- **Карточка способа помощи → `<article>`**, а не `<div>`:
  у неё есть собственный заголовок (`<h3>`) и самостоятельное
  содержание. Это отдельная сущность, а не визуальная обёртка.

- **Карточка приюта → `<article>`**: у неё есть название,
  адрес, описание и фото — самостоятельная единица контента.
  Изображение и текст лежат прямо внутри `<article>`,
  технические обёртки не нужны.

- **Блок «Как можно помочь» → `<section>`**: тематическая
  группа карточек. Есть свой `<h2>`, но это не отдельная
  сущность уровня страницы.

- **`<div>` в текущей версии не используется**: все блоки
  имеют собственный смысл и получают семантический тег
  (`section` или `article`). Технические обёртки не требуются,
  потому что CSS-стилизация пока не подключена.

- **`<h1>` один** — в герой-блоке. Все крупные секции
  получают `<h2>`, карточки внутри — `<h3>`.

## Иерархия заголовков

- `<h1>` — «Помоги животным найти дом» (в герое)
- `<h2>` — «Как можно помочь»
  - `<h3>` — «Корм», «Лекарства», «Волонтёрство», «Финансы»
- `<h2>` — «Приюты рядом»
  - `<h3>` — название приюта
- `<h2>` — «Стать волонтёром»
