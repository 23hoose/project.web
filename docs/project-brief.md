# Project Brief — «Путь к дому»

## Название и тип продукта

«Путь к дому» — веб-сервис с информацией о приютах для животных
и возможностях помощи.

## Проблема, которую решает продукт

Люди, готовые помочь животным, часто не знают, какие приюты есть
рядом, как туда добраться и что конкретно требуется: корм, лекарства,
финансы или волонтёрское время. Информация разбросана по соцсетям,
чатам и разным сайтам — её сложно найти и сравнить.

## Целевой пользователь

- Городские жители, готовые помогать животным.
- Потенциальные волонтёры.
- Люди, ищущие питомца.
- Доноры, желающие поддержать конкретный приют.

## Основной пользовательский сценарий

1. Пользователь заходит на главную страницу.
2. Видит, какие способы помощи существуют (корм, лекарства,
   волонтёрство, финансы).
3. Просматривает приюты рядом с собой.
4. Оставляет заявку на волонтёрство через форму.
5. Сотрудник приюта связывается с пользователем.

## Цель выбранной страницы

Главная страница должна:
- объяснить, чем занимается проект;
- показать основные способы помощи;
- представить приюты;
- дать возможность оставить заявку через форму.

## Ограничения текущей итерации

На этом этапе реализуется только структура и семантика HTML.
